# Evidências visuais

Esta pasta contém imagens utilizadas na documentação e na apresentação do projeto.

## Evidências planejadas

- máquina em funcionamento;
- condição de alarme;
- terminal Python;
- arquivo CSV;
- configuração do mapeamento Modbus.

As imagens devem utilizar apenas dados simulados e não podem conter informações de clientes, empresas ou projetos confidenciais.

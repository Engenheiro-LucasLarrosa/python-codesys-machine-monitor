# Requisitos

## Requisitos funcionais

- RF-001: permitir ligar e desligar a máquina simulada.
- RF-002: incrementar o contador de produção durante o funcionamento.
- RF-003: simular a temperatura do equipamento.
- RF-004: ativar um alarme acima do limite configurado.
- RF-005: disponibilizar as variáveis por Modbus TCP.
- RF-006: registrar os dados coletados em CSV.

## Requisitos não funcionais

- RNF-001: o código Python deve ser dividido em funções.
- RNF-002: falhas de comunicação devem gerar mensagens compreensíveis.
- RNF-003: nenhuma informação confidencial de clientes será utilizada.
